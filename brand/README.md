# 브랜드 에셋 (배포되지 않음)

구글·카카오가 배포하는 로그인 버튼 원본 키트. `public/`에 두면 빌드 결과에
그대로 실려 나가므로(작업용 .psd까지 공개된다) 여기로 옮겨 두고 참고만 한다.

## 앱에서 실제로 쓰는 것

키트의 완성 버튼 이미지는 **구글은 영어, 카카오는 한국어/영어만** 있다.
이 앱은 13개 언어라 그대로 쓰면 나머지 11개 언어에서 버튼만 영어가 된다.
그래서 두 브랜드 모두가 허용하는 "직접 만든 버튼 + 공식 심벌" 방식을 쓴다 —
`src/shared/SocialLogo.vue`의 심벌과 `SettingsPage`/`OnboardingFlow`의 버튼.

여기 키트는 그 버튼이 따라야 할 값의 출처다.

| 값 | 출처 |
|---|---|
| 구글 버튼 테두리 `#747775` | `google/signin-assets/.../SVG/Light/*.svg` |
| 구글 버튼 높이 40px · 알약 모양 | 같은 파일 (viewBox 0 0 40 40 / 180 40) |
| 카카오 노랑 `#FEE500` · 글자 `#191600` | `kakao/ko/kakao_login_medium_wide.png` |
